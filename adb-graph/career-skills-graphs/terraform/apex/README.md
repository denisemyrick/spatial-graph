# APEX application export

`f100.sql` is the supplied export for application 100 (`ghc_dev`). Import it into the instructor's APEX workspace after Terraform provisions the database.

The export uses APEX Accounts authentication. That account is separate from the `GHC_DEV` database user created by Terraform.
